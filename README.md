# tantripradipta-portfolio
Personal portfolio website Tantri Pradipta Kusumawardani

## Guestbook comments

Comments are stored in Supabase. To enable them:

1. Run `supabase.sql` in the Supabase SQL Editor.
2. Set `supabaseUrl` and the project's publishable/anon key in `js/comments-config.js`.
   Do not use a `service_role` key in this public website.
3. Deploy the site as a static website. Comments are public and appear immediately.
